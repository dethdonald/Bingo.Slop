# Bingo Slop

A big-number 75-ball bingo caller built for phones. Tap to call numbers yourself, or switch to **Voice caller** mode and let your phone read each number aloud (great through a Bluetooth speaker), with an optional auto-call timer.

**Play it:** https://dethdonald.github.io/Bingo.Slop/

On your phone, use *Add to Home Screen* to open it full-screen like an app.
